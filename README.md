# HIT137-Assignment-3-S2-2026-DAN.EXT-03
A desktop application where a loaded image is cut into a scrambled grid of tiles. The picture is programmatically transformed by moving, rotating, and flipping pieces. The player interacts with tiles to restore the image, while the app tracks moves, offers hints, and detects when it is fully restored.

Run these commands from the project folder:

```sh
python main.py                      # Load all modules and open the GUI
python main.py main_window          # Run only the GUI
python main.py puzzle               # Run only the puzzle module
python main.py --check              # Check all imports without opening a window
python main.py image_processor --check
```
